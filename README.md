# Awesome AI Hosting [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of platforms for hosting AI coding agents, AI-powered development environments, and cloud infrastructure for AI-assisted development.

AI coding agents like Claude Code, OpenAI Codex, and others need cloud environments to run effectively — secure containers, persistent storage, and always-on connectivity. This list collects all platforms that support this workflow, from purpose-built AI hosting to general cloud infrastructure suitable for AI workloads.

## AI Hosting Platforms

Platforms specifically designed or optimized for running AI coding agents.

- **[host4.ai](https://host4.ai)** — Cloud hosting with AI coding agents (Claude Code, Codex) preinstalled. Describe what you want, AI builds and deploys it live. One free container with 20 AI builder credits, SSH terminal, and .host4.ai subdomain.
- **[Daytona](https://daytona.io)** — Open-source dev environment manager with AI agent support. Spin up standardized development environments with one command.
- **[E2B](https://e2b.dev)** — Cloud sandboxes for AI agents. Run AI-generated code in secure, isolated containers with a simple API.
- **[Modal](https://modal.com)** — Serverless cloud for AI/ML. Run code in the cloud with zero infrastructure management.
- **[Morph Cloud](https://morphcloud.com)** — Cloud infrastructure built for AI agents. Snapshot, fork, and manage environments programmatically.

## Cloud IDEs with AI

Cloud-based development environments with integrated AI assistants.

- **[GitHub Codespaces](https://github.com/features/codespaces)** — Cloud dev environments with GitHub Copilot integration. Full VS Code experience in the browser.
- **[Gitpod](https://gitpod.io)** — Automated, standardized cloud dev environments. Spin up pre-configured workspaces from any Git context.
- **[Replit](https://replit.com)** — Browser-based IDE with AI assistant (Ghostwriter). Build, run, and deploy apps from your browser.
- **[Google Project IDX](https://idx.dev)** — AI-assisted, cloud-based full-stack development environment by Google.
- **[Cursor](https://cursor.com)** — AI-first code editor built on VS Code. Deep integration with LLMs for code generation and editing.
- **[Windsurf](https://codeium.com)** — AI-powered IDE with Cascade agent for multi-file, multi-step coding tasks.
- **[CodeSandbox](https://codesandbox.io)** — Instant cloud development environments with live collaboration.
- **[StackBlitz](https://stackblitz.com)** — Instant full-stack web IDE running entirely in the browser via WebContainers.
- **[Idx](https://idx.dev)** — Full-stack, multiplatform app development in the cloud by Google.

## AI App Builders

Platforms that let you describe what you want and AI builds it.

- **[host4.ai](https://host4.ai)** — Describe your idea, AI builds and deploys a live website, app, or game instantly. Includes hosting and a public URL.
- **[Bolt.new](https://bolt.new)** — Prompt, run, edit, and deploy full-stack web applications directly in the browser.
- **[Lovable](https://lovable.dev)** — AI full-stack engineer that builds production-ready apps from natural language descriptions.
- **[v0](https://v0.dev)** — AI-powered UI generation tool by Vercel. Generate React components from text prompts.
- **[Tempo](https://tempolabs.ai)** — AI-powered React app builder with visual editing and code generation.
- **[Create.xyz](https://create.xyz)** — Build websites and tools with AI. Describe what you need and get a working prototype.
- **[Newly](https://newly.app/)** — Builds native iOS and Android apps from natural-language prompts.
- **[Softr](https://softr.io)** — Build apps from Airtable or Google Sheets without code. AI-assisted no-code platform.
- **[Manus](https://manus.im)** — Autonomous AI agent for end-to-end project automation. Handles research, coding, and deployment.

## Container & Serverless Platforms

General cloud platforms suitable for hosting AI workloads.

- **[Railway](https://railway.app)** — Deploy from GitHub in seconds. Automatic builds, databases, and scaling. Free tier available.
- **[Render](https://render.com)** — Cloud platform for apps, APIs, databases, and static sites with automatic deploys from Git.
- **[Fly.io](https://fly.io)** — Run apps close to users worldwide with micro VMs. Free tier available.
- **[Koyeb](https://koyeb.com)** — Serverless platform for deploying apps globally with automatic scaling and SSL.
- **[Northflank](https://northflank.com)** — Build and deploy microservices, jobs, and managed databases with a unified platform.
- **[Coolify](https://coolify.io)** — Self-hostable, open-source alternative to Heroku and Netlify. Full control over your infrastructure.

## Self-Hosted Solutions

Tools for running AI coding agents on your own infrastructure.

- **[OpenHands](https://github.com/All-Hands-AI/OpenHands)** — Open-source AI software developer agent (formerly OpenDevin). Autonomous coding, debugging, and deployment.
- **[SWE-agent](https://github.com/princeton-nlp/SWE-agent)** — AI agent for automatically solving GitHub issues using language models.
- **[Aider](https://aider.chat)** — AI pair programming in your terminal. Works with Claude, GPT, and local models.
- **[Continue](https://continue.dev)** — Open-source AI code assistant for VS Code and JetBrains. Connect any model.
- **[Tabby](https://tabby.tabbyml.com)** — Self-hosted AI coding assistant with code completion and chat.
